🖐 Gesture Dataset Builder

自动构建手势识别训练数据集

📖 项目简介

本项目用于将手机拍摄的手势照片自动转换为深度学习训练数据集。

程序会自动：

  • 扫描所有手势类别文件夹
  • 随机打乱图片顺序
  • 按照 80% / 20% 自动切分
  • 生成 train 与 val 数据集
  • 兼容 PyTorch 与 TensorFlow 项目

📂 原始数据结构

gesture_raw/
├── fist/
├── open/
├── ok/
└── peace/

🎯 自动生成结果

gesture_dataset/
├── train/
│   ├── fist/
│   ├── open/
│   ├── ok/
│   └── peace/
│
└── val/
    ├── fist/
    ├── open/
    ├── ok/
    └── peace/

⚙️ 工作流程

  1. 读取 gesture_raw 目录
  2. 获取所有类别名称
  3. 随机打乱图片顺序
  4. 按 80% 划分训练集
  5. 按 20% 划分验证集
  6. 自动复制到目标目录

💻 核心代码

import os
import shutil
import random

RAW_DATA_DIR = "C:/gesture_raw"
TARGET_DATA_DIR = "C:/gesture_dataset"

SPLIT_RATIO = 0.8

for split in ['train', 'val']:
    os.makedirs(
        os.path.join(
            TARGET_DATA_DIR,
            split
        ),
        exist_ok=True
    )

categories = [
    f for f in os.listdir(RAW_DATA_DIR)
    if os.path.isdir(
        os.path.join(
            RAW_DATA_DIR,
            f
        )
    )
]

for category in categories:

    cat_dir = os.path.join(
        RAW_DATA_DIR,
        category
    )

    images = [
        img for img in os.listdir(cat_dir)
        if img.lower().endswith(
            ('.png','.jpg','.jpeg')
        )
    ]

    random.seed(42)
    random.shuffle(images)

        len(images) * SPLIT_RATIO
